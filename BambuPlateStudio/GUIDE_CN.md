# Bambu Plate Studio 使用说明

当前为 Windows 开发预览版。已在本机 Fusion 和 Bambu Studio 中验证纸巾盒模型，尚未完成跨版本及全部鼠标操作验收。

0.1.1 已修复“重新打开文档后，仅因网格顺序变化而丢失盘位”的问题。更新后在模型与布局正确时重新保存一次规则；旧版文件若已提示布局失效，仍需重新排盘并保存，不能从旧散列值直接重建缺失的盘位证明。

## 打开插件

0.1.2 增加手动跨色换盘确认。默认逐次确认；“允许手动混色盘”开关可跳过逐次确认，切换该开关不再清空布局。目标盘的确认许可随规则保存，自动重新排盘时清除。

本机已将 `I:\3DPrint\BambuPlateStudio` 注册到 Fusion 的加载项管理器，未设置开机自动运行。

在其他位置使用预览包时：

1. 解压，保留 `BambuPlateStudio` 文件夹名称及内部目录结构。
2. 打开 Fusion 的“脚本和附加模块”，使用添加本地脚本/加载项的入口，选择这个文件夹。
3. 选择 `BambuPlateStudio` 并运行。窗口默认 1460 × 920，可调整大小。
4. 点击“读取当前设计”。本机应已安装 Bambu Studio；插件不需要 MCP、网络服务或外部 Python。

文件夹、Python 入口与 manifest 同名的结构，以及添加本地加载项的方式，遵循 [Autodesk 加载项说明](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/WritingDebugging_UM.htm)。

## 配置与模型准备

- 默认 P2S、0.4 mm 喷嘴、Generic PETG、低温增稳板（Cool Plate SuperTack）。温度等设置读取本机 Bambu 预设。
- “打印配置”允许切换打印机、喷嘴、打印板、工艺及耗材；每种颜色可指定对应耗材预设。
- 颜色来自实体外观，不把 Fusion 中的“钢”等物理材质作为实际打印耗材。多面混色实体需要明确指定整件打印颜色。
- 组合视图中的模型是独立缩放的真实网格缩略展示，模型之间的屏幕距离不代表装配距离。

## 分组与方向

- 在“组合模型”中，将模型拖到另一模型上，松开后组成不可拆整体。
- 采用目标组的打印方向；组内各实体保持 Fusion 原装配位置关系，不会按屏幕上的拖动距离拼接，不进行布尔合并。
- 选择“选择贴板面”，拖动旋转查看，滚轮缩放；悬停高亮平面，单击使该面方向朝下。旋转相机不会改变打印方向。
- 真实 BRep 平面由 Fusion 再次校验；网格体使用右侧的方向选项。
- “解除当前整体”只解除分组，成员仍保留在当前盘，并保持原位置、相对高度和方向；其他单元不变。若独立模型的占地重叠或存在离板高度，会提示检查，不自动挪动或重新排盘。明确重新选择贴板面或自动排盘时才重新置底。
- 分组、方向、配置和位置修改可撤销/重做；重新读取模型或切换预设来源会清空历史。

## 排盘与导出

1. 点击“自动按色分盘”。首个模型优先放在盘中央，其他模型围绕中央向周围排列；中央有禁用区域时避让到附近安全位置。算法保留已指定的贴板方向，只允许按设置绕打印板 Z 轴旋转。
2. 左侧树按“打印盘 → 打印单元/整体 → 组内实体”排列。拖到目标盘标题，或拖到该盘内另一个模型节点，均只执行换盘，绝不会合成整体。组合整体请使用中央三维组合视图。
3. 打印盘视图支持拖动模型调整位置；右侧可精确输入盘号、X/Y 和盘内旋转角度。
   预览区上方可通过“当前盘”下拉框或“上一盘／下一盘”切换查看。左侧点击盘标题只切换预览，点击小箭头才展开或收起成员列表；两种操作互不联动。
4. 跨颜色/耗材换盘会弹出确认；取消保留原盘，确认仅移动当前整体并记录目标盘的混色许可，不清空其他盘位。空间不足仍会拒绝移动。确认后的换盘支持撤销，自动排盘仍按颜色分开。
5. 当前工艺的裙边/支撑占地会重新计算，不信任旧规则中的零预留量；本次 PETG 工艺预留 5.1 mm，仍需实际切片复核。
6. 点击“导出完整 3MF”，选择尚不存在的 `.3mf` 文件名。插件调用本机 Bambu 原生读写并检查几何保真，生成一个包含全部打印盘的项目。
7. 用 Bambu Studio 打开项目，检查全部打印盘并执行切片。插件不会向打印机发送任务。

“保存规则”只将准备规则写入 Fusion 文档属性；还需要自行保存 Fusion 文档，才能在以后重新打开时保留这些规则。插件不修改原实体几何、颜色或组件层级。

## 已知限制

- 排盘使用保守包围矩形，不保证最少盘数。超大模型不会自动缩放或拆分。
- 不自动修复原网格异常；本次五个实体存在原网格警告，已保留并通过切片测试。切片通过不等于实体几何已修复或实际打印必定成功。
- 当前以 Windows、矩形打印区域、单喷嘴配置为验证范围。其他环境及复杂嵌套实例仍需另行测试。
- 本机的系统窗口截图接口不兼容，故完整 Fusion 窗口鼠标操作尚未全部验收；已验证正式加载项启动、前端实际画布、真实 API 编辑/恢复/导出和 Bambu 全盘切片。

## 停止或更新

在 Fusion 加载项管理器中停止 `BambuPlateStudio`，再替换插件文件并重新运行。替换前保留自己的插件备份和 Fusion 文档。不要在插件运行时直接覆盖目录，也不要为了更新插件强制结束未保存的 Fusion 文档。
