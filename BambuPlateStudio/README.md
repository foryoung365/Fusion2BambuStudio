# MF3D打印摆盘助手（开发中）

Fusion 加载项：读取当前设计 → 指定不可拆打印组/贴板面 → 选择本机 Bambu 预设 → 按色排盘 → 手动编辑 → 单个多盘 3MF。

默认：P2S、0.4 mm、Cool Plate SuperTack、Generic PETG。温度来自本机真实预设，不从 PLA 配置复制。

## 范围与安全边界

- 原设计几何、颜色、组件层级不修改；只在用户选择保存规则时写入文档属性。
- 不可拆组采用统一刚体变换，不布尔合并、不按实体分别置底。
- 默认不倾斜零件；用户可点选平面朝下，或确认本机 Bambu 引擎的自动朝向建议。自动排盘本身最多绕打印板 Z 轴旋转。
- 不从 CAD“钢”等物理材质推断耗材；逐对象读取 RGB，不以可能重复的 Appearance.id 缓存颜色。
- 多面混色实体需要用户指定整件颜色；不同颜色的不可拆组保持同盘并明确提示。
- 自带按色排盘器使用保守包围矩形；不宣称达到最少盘数。Bambu 自动摆位可在预览确认后新增打印盘，不拆分打印整体或改变朝向。超大对象不自动缩放或拆分。
- 第一阶段支持矩形打印板、单喷嘴机型。不可解释的兼容性条件或缺失预设会阻止导出。
- 导出与切片验证分开；ZIP/XML 合格不代表 Bambu 已成功载入或切片。
- 不自动修复原网格，不上传文件，不向打印机发送任务。

## 验证计划（未完成前不视为交付）

1. 独立单元测试：分组刚体不变量、贴板矩阵、毫米单位、颜色、预设继承、排盘/编辑边界、XML 入口和对象引用。
2. Fusion 实机：加载 GUI，读取当前文档，编辑打印组/贴板方向，保存并恢复规则，导出后比较源设计未改变。
3. Bambu Studio 实机：实际载入完整 3MF，检查盘/对象/颜色/分组，并完成切片测试。

## 开发加载方式

在 Fusion 的“脚本和附加模块”管理器中，将本目录添加为加载项目录并运行 `BambuPlateStudio`。入口与 manifest 文件名一致，运行时只依赖 Fusion 自带 Python 和本机 Bambu Studio，不依赖 MCP。

默认使用 1460 × 920 的可调整大小浮动窗口，最小 1020 × 680，不停靠在侧边栏。原生三页窗口保留为兼容入口。

## 可视化操作

- **组合模型**：显示真实彩色网格的缩略陈列（各单元独立缩放，仅为便于选择）。将模型拖到另一模型上建立不可拆打印组；保留原装配坐标关系，采用目标组的方向，不按屏幕摆放位置拼接实体。
- **选择贴板面**：单独显示所选组，拖动旋转查看、滚轮缩放，悬停高亮共面区域。单击后由 Fusion 校验真实 BRep 平面并使其朝下；曲面或无法匹配的面会拒绝。网格体可使用方向选项。查看相机不会改变打印方向。
- **打印盘预览**：按实际毫米位置显示彩色模型与打印板。模型可拖动调整盘内位置；左侧按“打印盘 → 打印整体 → 实体”排列，拖动整体节点或单元节点至盘标题进行换盘。组内实体锁定，不可直接拆开拖动。
- 换盘保持方向，检查颜色/耗材、边界和空间；无法放入时保留原位置。分组与方向修改后仍需处理可能出现的排盘错误。
- 0.1.2：跨色手动换盘先弹出确认，确认只授权目标盘；取消不会改变布局。成功后自动显示目标盘，不更改自动按色分盘算法或全局混色开关。
- 左侧树的模型节点和盘标题都只用于换盘，与中央当前模式无关；组合整体只在中央组合视图完成。0.1.4 解除整体后成员仍在原盘，保留原三维位置与方向，不再转为未分盘或重新摆放。原本未分盘的整体解除后仍未分盘。
- 0.1.5 自动摆盘优先从中央开始，后续模型围绕已有布局向周围扩展，并保持整盘布局居中。中央受禁用区域阻挡时选择最近可行位置；仍按颜色分盘，不缩放或倾斜打印单元。
- 0.1.6 打印盘预览提供独立选盘下拉框和上一盘/下一盘按钮。左侧盘标题仅切换预览，箭头仅展开/收起列表；切换不会修改盘位或折叠状态，首末盘自动禁用相应方向按钮。
- 0.1.7 可为所选打印单元调用本机 Bambu 自动朝向引擎。不可拆组作为一个临时查询网格，返回结果须通过刚体与网格保真校验；仅显示双视图建议，确认后才改该单元的打印规则，可撤销。手动指定方向自动锁定，解除锁定后才可请求建议；原 Fusion 几何不变。
- 0.1.8 新增“当前盘 / 所有盘”的 Bambu 自动摆位。逐盘查询引擎，双视图预览后确认；校验组内刚体关系、几何、颜色、盘号与朝向，只导入 X/Y，可撤销。若引擎建议拆到其他盘，“所有盘”模式会跳过该盘并明确提示。未明确启用的自动裙边不再按固定 5.1 mm 当作硬碰撞；潜在裙边空间改为警告，实际出板与配置边距分开提示。
- 0.1.9 自动朝向范围增加“所选件 / 当前盘 / 所有盘”。批量模式逐单元查询 Bambu，引擎失败或锁定方向的单元跳过并注明原因；已有不可拆整体保持整体。双视图逐盘预览，确认后作为一次编辑应用并可一次撤销。不暗中换盘；新朝向引起的排盘冲突会列出，需随后摆位并在导出前处理。朝向和摆位查询最多并行两个互相隔离的 Bambu 进程，等待期间界面显示已用时间。
- 自动摆位的临时查询允许已有 XY 冲突，以便修复批量朝向后产生的重叠；这不会放宽正式 3MF 导出。Bambu 建议位置仍须通过完整校验才能确认应用。
- 0.1.10 将范围下拉框替换为直接入口：左侧“所有盘自动摆放／所有盘自动朝向”，打印盘预览栏“整盘自动摆放／整盘自动朝向”，右侧所选单元“自动朝向”。窗口与 Fusion 命令显示名改为“MF3D打印摆盘助手”，页眉以小号字显示版本；内部加载项目录仍为 `BambuPlateStudio`。
- 0.1.11 导出同名 3MF 时要求再次确认。先生成并核验 Bambu 原生项目，再在目标目录暂存完整文件并替换；取消、生成失败、校验失败或替换失败均不由插件改动旧文件。导出期间若旧文件被其他程序改动，也拒绝覆盖。
- 0.1.12 自动朝向与自动摆位改为后台计算，窗口持续响应并在计算完成后显示确认预览；间距校验改用实体投影轮廓，避免凹形模型的包围矩形误报。新文档的默认件间距为 0（不额外强制固定距离，自动摆放遵循 Bambu 引擎的当前打印设置，实际实体重叠仍拦截）；板边距仍为插件设置的 5 mm。旧文档中保存的间距不会被覆盖。
- 0.1.13 Bambu 建议拆盘时不再跳过：预览列出新增盘及其打印单元，原有盘号不变；确认后才新增盘并应用盘内位置，可一次撤销。仍校验整体、颜色、朝向、板边距及间距。若仅当前件间距规则挡住 Bambu 建议，可明确选择把当前文档件间距改为 0 mm 后应用；真实重叠或出板不能借此通过。
- 分组、方向、位置与配置编辑支持撤销/重做。重新读取设计或切换预设来源会清空编辑历史。
- “打印配置”打开较大的设置窗口；默认 P2S / 0.4 mm / PETG / SuperTack。点击“保存规则”才将准备规则写入文档属性，仍需自行保存文档。

`tests/visual_demo_server.py` 使用已有实际网格提供本地离线交互测试，页面明确标注“非 Fusion 实测”；测试页面不会导出项目、发送打印任务或修改 Fusion。离线点面只验证交互回调，不代替真实 BRep 面校验。

开发过程中使用 MCP import/run 的事件生命周期与正式加载项管理器不同。热重载应清理本插件旧事件、再刷新所有子模块，不应只替换主模块。详见 `WORKLOG.md`。
