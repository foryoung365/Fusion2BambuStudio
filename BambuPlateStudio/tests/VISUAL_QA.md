# 可视化界面开发验证

2026-09-07，使用 `visual_demo_server.py` 与本地内嵌浏览器，在 1280 × 720 视口测试。

## 已观察结果

- 从已捕获的实际 3MF 加载 27 个实体、22 个打印单元、8 盘；不是示意方块。
- 彩色模型、树节点模型缩略图、不可拆六件组、配置和检查区域均实际显示。
- 从模型表面拖动“金色骨架”至“金色风口”后，单元数变为 21；目标显示两件整体。撤销恢复为 22，原六件组保持完整。
- 在独立视图点击底板平面后收到方向回调，撤销恢复。离线服务器仅演示三角面方向，未验证 Fusion BRep 面匹配。
- 选择第二盘后，显示蓝色裙甲的真实网格与打印板网格。
- 将树中的右胸拖到第四盘，收到空间不足提示；仍保留第一盘的两件单元与第四盘的两件单元，没有偷偷移位或缩放。
- 原生 HTML 拖放在本次浏览器中未稳定触发，改为树容器的指针捕获后，换盘请求正常触发。跨盘成功移动的核心逻辑另有 Python 测试；大型滚动树和 Fusion 内指针行为仍待实机验证。
- 修正观察相机只能从上方旋转的问题；新增回归覆盖底部观察和投影/拾取坐标一致性。
